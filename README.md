# Louvores ICNV — Progressive Web App (PWA)

Coletânea de louvores e cifras interativa pronta para deploy no **GitHub Pages**.

## 🚀 Como publicar no GitHub Pages

1. Crie um novo repositório no GitHub (ex: `louvores-icnv`).
2. Extraia o conteúdo deste arquivo `.zip` na raiz do seu repositório local/GitHub.
3. Faça o commit e push dos arquivos para o branch `main` ou `gh-pages`.
4. No GitHub, vá em **Settings** > **Pages**.
5. Em **Source**, selecione `Deploy from a branch`, escolha a branch `main` (ou `gh-pages`) e a pasta `/ (root)`.
6. Clique em **Save**. Em alguns segundos, o seu app estará no ar com suporte PWA completo e funcionamento offline!

## 📱 Instalação no Celular / Tablet

- **Android (Chrome):** Acesse o site publicado, clique nos três pontos no canto superior e selecione **"Adicionar à tela inicial"** ou **"Instalar aplicativo"**.
- **iOS / iPhone (Safari):** Acesse o site, toque no botão de **Compartilhar** e selecione **"Adicionar à Tela de Início"**.
